# lms-react

This workspace contains a starter monorepo for a React-based Laboratory Management System.

## Projects

- `frontend` — Vite + React + TypeScript
- `backend` — Express + TypeScript

## Setup

1. Run `npm install` at the repository root.
2. Run `npm run dev` to start both frontend and backend concurrently.

## Notes

- Frontend development server runs on `http://localhost:4173`
- Backend API server runs on `http://localhost:5000`
